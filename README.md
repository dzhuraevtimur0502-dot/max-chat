# MAX Chat - Тестовое задание

Пользовательский интерфейс для отправки сообщений в MAX через GREEN-API.

## Функционал

✅ Авторизация через GREEN-API (idInstance + apiTokenInstance)
✅ Создание нового чата по номеру телефона
✅ Отправка текстовых сообщений
✅ Отображение статуса доставки (галочки V)
✅ Интерфейс в стиле MAX Messenger

## Технологии

- React 18
- Vite
- GREEN-API (https://green-api.com/max)
- JavaScript (ES6+)
